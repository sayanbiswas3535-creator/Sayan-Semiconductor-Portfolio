# Sayan Biswas — Semiconductor Portfolio Starter

## Run locally
1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open http://localhost:3000

## Deploy
1. Create a GitHub repository and push this project.
2. Import the repository into Vercel.
3. Deploy with the default Next.js settings.
4. Replace the placeholder Vercel URL in `public/robots.txt` and `public/llms.txt`.
5. Add your email and LinkedIn URL in `app/page.tsx` and `public/llms.txt`.

## Before making public
- Replace all placeholders.
- Add a downloadable resume only after checking it for personal contact details you intend to publish.
- Replace the case-study frameworks with accurate, non-confidential project narratives.
- Add only metrics you can substantiate and are permitted to disclose.
- Confirm employer names, titles and dates.
- Do not publish confidential customer, product roadmap, revenue or internal company information.

## Important
`robots.txt` expresses crawler preferences; it does not guarantee crawling, indexing, AI citations or recruiter discovery. `llms.txt` is a supplementary context file, not a ranking or hiring guarantee.

## GitHub setup (first-time user)
1. Create a free account at https://github.com/signup.
2. Verify your email and sign in.
3. Download and extract this project ZIP on your computer.
4. On GitHub, click **New repository**. Name it `sayan-semiconductor-portfolio`. Choose **Public** if you want recruiters to view the source, or **Private** if you prefer not to expose the code. Do not initialize it with a README, license or .gitignore.
5. Install GitHub Desktop from https://desktop.github.com/. Sign in to your GitHub account.
6. In GitHub Desktop choose **File → Add local repository** and select the extracted project folder. If prompted that it is not a Git repository, choose **create a repository**.
7. Commit the files with a message such as `Initial semiconductor portfolio`.
8. Choose **Publish repository**, select the repository you created and publish.
9. In Vercel, choose **Add New → Project**, connect GitHub, import `sayan-semiconductor-portfolio`, keep the detected Next.js settings and deploy.

GitHub Desktop avoids needing command-line Git for the initial setup. Keep the repository private until you have reviewed the source for confidential employer or customer information if that is your preference.
